# AI-Based Phishing Email Detection

A semester project to classify emails as legitimate, suspicious, or phishing using machine learning.

## Planned stack
- Python
- Pandas and NumPy
- Scikit-learn (TF-IDF + Logistic Regression baseline)
- Flask
- HTML/CSS/Bootstrap
- Joblib

## Project status
Folder structure only. The model and web app have not been implemented yet.

## Getting started
1. Create and activate a Python virtual environment.
2. Install dependencies from `requirements.txt`.
3. Put the original dataset in `data/raw/`.
4. Explore and preprocess the data in `notebooks/`.
5. Implement reusable code in `src/`.
6. Train and save the model under `models/`.
7. Run the Flask app with `python app.py` once the app is implemented.

See `docs/PROJECT_PLAN.md` for the 30-day plan.
