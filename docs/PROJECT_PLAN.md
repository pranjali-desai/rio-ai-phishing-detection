# 30-Day Plan

## Week 1: Setup and data
- Days 1-2: Set up environment and inspect dataset options.
- Days 3-5: Download, inspect, clean, and explore labeled email data.
- Days 6-7: Learn TF-IDF and prepare a train/test split.

## Week 2: Machine learning
- Days 8-10: Train TF-IDF + Logistic Regression baseline and evaluate it.
- Days 11-12: Compare Multinomial Naive Bayes; analyze false negatives.
- Days 13-14: Save the best pipeline and document results.

## Week 3: App and risk indicators
- Days 15-18: Add validated URL/sender features, score, and explanations.
- Days 19-21: Connect the model to Flask and finish the web interface.

## Week 4: Submission
- Days 22-25: Test, inspect errors, and polish the UI.
- Days 26-28: Finish report and slides.
- Days 29-30: Rehearse demo, fix issues, and submit.

Keep the first working version small. Do not add Gmail integration or browser extensions until the core system works.
